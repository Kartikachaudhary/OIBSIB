# Verdant & Co. — Small-Batch Loose Leaf Tea

A responsive single-page website created as part of my **Oasis Infobyte Web Development Internship — Task 1**.

The project is a modern landing page for **Verdant & Co.**, a fictional small-batch loose-leaf tea brand. The website focuses on creating a clean, elegant, and responsive user experience using HTML and CSS.

## Internship / Task Description

The objective of this task was to design and develop a responsive webpage while applying fundamental front-end web development concepts.

For this task, I created a tea-brand landing page that presents the brand, its tea origins, product collection, brewing ritual, and contact information in a structured and visually appealing layout.

## Task Objectives

* Create a clean and professional landing page.
* Structure the webpage using semantic HTML.
* Design the interface using CSS.
* Create different sections for the website content.
* Implement navigation between sections.
* Add hover effects and visual styling.
* Make the website responsive for different screen sizes.

## Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layouts, animations, and responsiveness
* **Google Fonts** — Fraunces and Work Sans typography

## Features

* Sticky navigation bar
* Hero section with call-to-action button
* Tea origin section featuring three growing regions
* Product collection section with four tea products
* Tea ritual/testimonial section
* Responsive grid layouts
* Hover effects on buttons and navigation links
* Custom color palette and typography
* Responsive design for desktop, tablet, and mobile screens
* Smooth scrolling navigation

## Brief

**Verdant & Co.** is designed as a premium tea-brand landing page with a calm, natural visual style.

The website contains information about different tea-growing regions, a collection of four teas, a simple tea-brewing ritual, and brand/contact information.

The layout changes according to screen size using CSS media queries, making the website usable on desktop, tablet, and mobile devices.

# Personal Portfolio Website

A responsive personal portfolio website created as part of my **Oasis Infobyte Web Development Internship — Task 2**.

The project presents a simple personal profile with sections for introduction, skills, projects, and contact information.

## Internship / Task Description

The objective of this task was to create a personal portfolio webpage using HTML and CSS.

I designed a clean and responsive portfolio website with a simple navigation system and separate sections to introduce myself, showcase my technical skills and projects, and provide contact information.

## Task Objectives

* Create a personal portfolio webpage.
* Structure the website using HTML5.
* Design the interface using CSS3.
* Create separate sections for About, Skills, Projects, and Contact.
* Implement responsive layouts for different screen sizes.
* Add navigation and interactive hover effects.
* Maintain a consistent visual design throughout the website.

## Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling, layouts, responsiveness, and hover effects
* **Google Fonts** — Space Grotesk, Inter, and JetBrains Mono

## Features

* Responsive navigation bar
* Hero/profile section
* About Me section
* Skills section
* Projects section
* Contact section
* Smooth scrolling navigation
* Responsive CSS Grid layouts
* Hover effects on buttons and links
* Custom CSS variables for colors, fonts, spacing, and other design values
* Mobile, tablet, and desktop responsive layouts

## Brief

The website starts with a hero section containing a profile avatar, introduction, role, short description, and two call-to-action buttons.

The **About Me** section provides a short introduction, while the **Skills** section displays C, C++, Python, Java, DBMS, and Frontend skills.

The **Projects** section contains three sample project cards covering Python, C++/DBMS, and HTML/CSS.

Finally, the **Contact** section provides an email address along with GitHub, LinkedIn, and LeetCode links.

* # 🌡️ Temperature Converter

A simple and responsive **Temperature Converter** built as part of my **Oasis Infobyte Web Development Internship**.

## 🚀 Features

* Convert between **Celsius, Fahrenheit, and Kelvin**
* Input validation for invalid values
* Prevents temperatures below absolute zero
* Clean and responsive interface
* Automatic conversion when the unit is changed

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)


## ▶️ How to Run

1. Download or clone the repository.
2. Open `task 3.html` in your browser.
3. Enter a temperature and select the unit.
4. Click **Convert** to view the results.

## 📚 What I Learned

This task helped me practice **DOM manipulation, JavaScript event handling, input validation, temperature conversion logic, and responsive CSS design**.
